# AGENTS.md

Operational and style guidance for AI agents working in this repo.

## Project shape

This is a single-page static site built with Astro. The page composes from
small components in `src/components/`. Content lives in `src/data/`. Pure
helpers go in `src/lib/` and are unit-tested with Vitest. Build-time data
fetching is in `scripts/fetch-repo-meta.ts`.

## Conventions

- **Commit style:** Conventional Commits (`feat:`, `fix:`, `chore:`, `docs:`,
  `build:`, `ci:`).
- **Testing:** Pure functions get Vitest tests; visual changes need browser
  verification before claims of "working." Don't claim a UI change works if
  you haven't seen it render.
- **Comments:** Default to none. Add only when the WHY is non-obvious.
- **No em-dash in source code, comments, or string literals.** Markdown prose
  is fine.
- **Hostname:** the `SITE_HOST` env var is the single source of truth. Local
  dev gets it from `.env` (gitignored); CI gets it from the `SITE_HOST` repo
  Variable. New hostname references read `process.env.SITE_HOST` directly and
  throw if unset. `public/CNAME` is generated by `scripts/write-cname.ts` and
  gitignored. Do not hardcode hostname literals in code, configs, or workflow
  YAML; documentation files (README, AGENTS.md, .env.example) may reference
  the value as documentation.

## What this repo is NOT

- Not a multi-page site. Don't add new routes without discussing.
- Not a blog. Don't introduce content collections, MDX, or `/posts/`.
- Not a contact form host. The only contact channel is the symlink list in
  `src/data/links.ts`.
- Not a CMS. Content edits are file edits.

## Style aesthetic

The terminal aesthetic is load-bearing. Don't add bright accent colors,
gradients, scroll animations, parallax, hover-glow effects, or other
"corporate-portfolio" treatments. Match the existing palette
(`src/styles/global.css`).
